# 桌面設置分層與主窗縮放

> **部分被 [0009](./0009-duty-desk-and-settings-center.md) 取代**：關鍵詞獨立頂欄作為主路徑、以及全局／平台／實例三套設置並列的組織方式，改為單一 SettingsCenter；首屏改為 DutyDesk。下文中「主窗可縮放」「本店資料以 Shop 為作用域」「未綁定先引導綁定」仍然有效。

右上「關鍵詞」為按 Shop 的工作台入口（進門選／切店），實例齒輪不編關鍵詞（G27）。右上「設置」只留網關帳戶、本機自動回覆行為默認、關於；實例齒輪只留綁定網關店與本店業務資料（物流／售後／禁答／轉人工／商品賣點等），原「店鋪知識」改由齒輪進入（G28）。實例未綁定網關店時齒輪仍可開，第一屏只做綁定，綁好再編本店資料（G30）。主視窗改為可縮放，默認 528×1024，最小約 480×720（G29）。曾考慮全公司一份關鍵詞、店鋪知識仍堆在右上、主窗完全不可縮、未綁定則禁用齒輪——分別因串店風險、每店設置過弱、與放大訴求相反、引導不清晰而排除。
